# Pixel Pet Assets

50x50 pixel-art pet assets based on the bronze armored axe guardian reference.

## Runtime Assets

- `bronze-guardian-idle.png` - static 50x50 idle sprite.
- `bronze-guardian-rage.gif` - 50x50 rage animation, 6 frames.
- `bronze-guardian-axe-hit.gif` - 50x50 axe-hit animation, 8 frames.
- `bronze-guardian-rage-sheet.png` - 6-frame sprite sheet, 300x50.
- `bronze-guardian-axe-hit-sheet.png` - 8-frame sprite sheet, 400x50.

## Preview Assets

- `bronze-guardian-rage-preview.gif` - 300x300 nearest-neighbor preview.
- `bronze-guardian-axe-hit-preview.gif` - 300x300 nearest-neighbor preview.

Use the 50x50 files in UI/runtime code. Use preview files only for docs or
human review.
